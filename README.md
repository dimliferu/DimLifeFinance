## DimLife Finance

**DimLife Finance** — Android-приложение для контроля личных финансов и подписок.

## Возможности текущего прототипа
- Главный экран с балансом, доходами и расходами
- Добавление, редактирование и удаление доходов и расходов
- Категории операций
- Локальная история операций
- Добавление, редактирование и удаление регулярных подписок
- Расчёт примерной месячной стоимости подписок
- Сводка аналитики по доходам и расходам
- Месячные бюджеты по категориям с индикатором остатка и превышения
- Поиск операций по названию и категории, фильтры доходов и расходов
- Сохранение выбранной темы между запусками
- Переключение светлой и тёмной темы
- Хранение записей в Room на устройстве

## Технологии
- Kotlin
- Jetpack Compose / Material 3
- Room
- DataStore
- WorkManager
- GitHub Actions

## Сборка APK
Каждый push в ветку `main` запускает workflow **Android CI**. Готовый debug APK публикуется как workflow artifact с именем `DimLife-debug-apk`.

## Важно
Приложение пока не подключается к банкам, не читает SMS и не синхронизирует данные с облаком. Все финансовые записи остаются в локальной базе приложения.

Подробности: [техническое задание](docs/TECHNICAL_SPECIFICATION.md).
