# DimLife

Локальный Android-помощник для учёта доходов, расходов и подписок.

## Технологии
- Kotlin
- Jetpack Compose
- Room
- DataStore
- WorkManager

## Сборка
Откройте проект в Android Studio либо запустите GitHub Actions workflow `Android CI`.

Данные финансовых операций хранятся локально на устройстве. Облачная синхронизация не используется.
